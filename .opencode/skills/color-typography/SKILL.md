# Color and Typography

Owned by `ui-design`. Feeds `design-tokens.json`.

## Color

- Define a primary, secondary, accent, and a neutral ramp.
- Provide semantic roles: background, surface, text, muted, border, success, warning,
  danger.
- Verify contrast: ≥ 4.5:1 for body text, ≥ 3:1 for large text and UI borders.
- Provide dark-mode variants when the brand calls for it.

## Typography

- Choose one or two typefaces (max three weights each for performance).
- Define a modular scale (e.g., 1.25 ratio) for h1–h6 and body.
- Set line-height (1.5 body) and measure (45–75 characters).
- Use system fonts as fallback.

## Rules

- Never rely on color alone to convey meaning.
- Keep the palette small; every color has a semantic role.
- Record all values as tokens, not inline hex.
