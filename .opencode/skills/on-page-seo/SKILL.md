# On Page SEO

Owned by `seo-specialist` with `content-writer`.

## Per-page checklist

- **Title** — unique, ≤ 60 chars, primary keyword near the front.
- **Meta description** — unique, 150–160 chars, compelling.
- **H1** — one per page, matches intent.
- **Headings** — logical H2/H3 hierarchy.
- **Body** — primary keyword in the intro and naturally throughout.
- **Internal links** — descriptive anchor text to related pages.
- **Images** — descriptive filenames and alt text.
- **URL** — short, readable, hyphenated.
- **Canonical** — set to the preferred URL.

## Rules

- No keyword stuffing; write for humans first.
- Every page has a unique title and description.
- Content satisfies search intent, not just contains keywords.
