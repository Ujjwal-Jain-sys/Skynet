# Visual Design

Owned by `ui-design`. Output: mockups + `design/component-specs.md`.

## Workflow

1. Read brand inputs and the audience from the requirements.
2. Establish a visual direction (mood, references, one-paragraph rationale).
3. Apply the design system: color, type, spacing, imagery.
4. Design key pages at desktop and mobile.
5. Annotate spacing, alignment, and hierarchy for handoff.

## Principles

- Hierarchy: one clear focal point per screen.
- Contrast: text always readable.
- Consistency: reuse tokens and components.
- Restraint: remove anything that does not serve the goal.

## Rules

- Design with the real content, not lorem ipsum.
- Respect accessibility contrast from the start.
- Output must be expressible in the frontend stack (Tailwind + components).
