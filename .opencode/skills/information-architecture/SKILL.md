# Information Architecture

Owned by `ux-architect`. Output: `docs/projects/<id>/sitemap.md` (refined) +
navigation notes.

## Workflow

1. Start from the sitemap and requirements.
2. Group content by user mental model, not org structure.
3. Define global navigation (header), local navigation, and footer.
4. Label everything in the user's language.
5. Define URL structure (readable, stable, SEO-friendly).

## Rules

- Maximum 7 top-level nav items; keep depth shallow.
- Every page is reachable within 3 clicks of home.
- URLs are lowercase, hyphenated, and descriptive.
- Hand the refined sitemap to `ui-design` and `seo-specialist`.
