# Landing Page Copy

Owned by `content-writer`.

## Structure

1. **Hero** — headline (outcome), subhead (how/who), primary CTA.
2. **Social proof** — logos, testimonials, numbers.
3. **Problem** — the pain the audience feels.
4. **Solution** — how the product solves it.
5. **Features → benefits** — 3–5, benefit-led.
6. **How it works** — 3 simple steps.
7. **Objections / FAQ**.
8. **Final CTA** — repeat the primary action.

## Rules

- One primary CTA repeated; secondary CTA clearly weaker.
- Every headline passes the "so what?" test.
- Use the audience's words, drawn from research.
- Keep above-the-fold copy to a headline, subhead, and CTA.
- Align with `on-page-seo` keywords without stuffing.
