# Monetization Strategy

Owned by `product-strategist`.

## Options

- **Direct sales / e-commerce** — products or services.
- **Subscription** — recurring access.
- **Lead generation** — capture enquiries for a service business.
- **Advertising / sponsorship**.
- **Freemium** — free tier with paid upgrades.
- **Donations / crowdfunding**.

## Workflow

1. Match the model to the audience and value proposition.
2. Define the primary conversion action (the one thing the site is optimized for).
3. Specify required features (payments, accounts, plans, gating).
4. Estimate pricing and note validation steps.

## Rules

- One primary model for the MVP; list alternatives as future options.
- Monetization features become requirements with ids; do not leave them implicit.
- Anything involving payments is a `must` security review item.
