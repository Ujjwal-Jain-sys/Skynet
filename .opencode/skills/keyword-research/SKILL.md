# Keyword Research

Owned by `seo-specialist`.

## Workflow

1. Start from the audience, value proposition, and pages.
2. Brainstorm seed terms per page.
3. Expand with related terms and questions (People Also Ask).
4. Classify intent: informational, navigational, commercial, transactional.
5. Map one primary keyword per page; add 3–5 supporting terms.

## Output

```markdown
| Page | Primary keyword | Supporting | Intent | Priority |
|------|-----------------|-----------|--------|----------|
```

## Rules

- One primary keyword per page (avoid cannibalization).
- Match intent to page type.
- Prioritize by relevance and winnability, not volume alone.
- Hand the mapping to `content-writer`.
