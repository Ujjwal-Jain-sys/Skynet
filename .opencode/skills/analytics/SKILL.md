# Analytics

Owned by `seo-specialist` with `devops`.

## Workflow

1. Define the primary conversion and key events from `mvp-scope.md`.
2. Add a privacy-respecting analytics tool.
3. Track page views and events (signup, form submit, purchase).
4. Verify events fire correctly before launch.
5. Build a small dashboard of the north-star metric.

## Rules

- Collect the minimum data needed.
- Disclose analytics in the privacy policy; honor consent.
- No PII in event payloads.
- Do not let analytics block page load.
- Document every tracked event and its meaning.
