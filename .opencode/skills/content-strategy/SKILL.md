# Content Strategy

Owned by `content-writer` with `seo-specialist`.

## Workflow

1. Map content to the sitemap and keyword research.
2. For each page define: audience, goal, primary message, CTA.
3. Decide what is static vs. dynamic vs. user-generated.
4. Plan a lightweight editorial calendar for ongoing content (blog, updates).
5. Define a maintenance and freshness plan.

## Output

```markdown
| Page | Audience | Goal | Primary message | CTA | Status |
|------|----------|------|-----------------|-----|--------|
```

## Rules

- No content without a purpose and a page.
- Align with SEO intent per page.
- Reuse where possible; avoid duplication.
- Flag content that needs ongoing updates.
