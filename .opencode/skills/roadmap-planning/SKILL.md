# Roadmap Planning

Owned by `product-strategist`. Output: `docs/projects/<id>/roadmap.md`.

## Phases

- **MVP** — smallest thing that delivers the core value proposition.
- **V1** — polish, secondary pages, analytics.
- **Later** — integrations, personalization, scale.

## Workflow

1. Take the walking skeleton from `user-story-mapping`.
2. Assign stories to phases by value and dependency.
3. State the exit criteria for each phase.
4. Note risks and unknowns per phase.

## Rules

- MVP must be shippable on its own.
- No phase depends on a later phase.
- Keep the roadmap short; it is a plan, not a wish list.
