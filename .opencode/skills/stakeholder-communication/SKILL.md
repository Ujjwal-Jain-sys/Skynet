# Stakeholder Communication

Owned by `project-manager`.

## Principles

- The user is non-technical; no jargon.
- Lead with outcomes ("your homepage is ready"), not activities.
- Be honest about delays and blockers.
- Offer choices with clear trade-offs, not open-ended questions.

## Workflow

1. Summarize progress in plain language.
2. Show what the user can see (preview link, screenshots).
3. State what is next and what is needed from them.
4. Surface decisions as simple options (A vs. B).

## Rules

- No internal agent names or file paths in user-facing updates.
- One clear ask per update.
- Confirm understanding when the user must decide.
- Keep the user informed at every phase gate.
