# Skynet

Build and deploy a website just by describing it — no coding required.

Skynet is a team of AI agents that takes your plain-language idea and turns it into a live website. You say what you want, and the agents research, plan, design, build, test, secure, and deploy it for you. You don't need to know code, design, or servers.

## What Skynet does for you

- **Describe in plain words** — tell Skynet what kind of site you want, like "a bakery website with online ordering"
- **Watch agents build it** — a team of AI specialists handles every step, from layout to launch
- **Get a live website** — your site is online with a real web address, ready for visitors
- **No technical skills needed** — no coding, no design tools, no server setup

## Try it in 30 seconds

```bash
# Tell Skynet what kind of website you want
/skynet-build "a portfolio site for my photography with a contact form"

# Check on progress anytime
/skynet-status

# Launch when everything is ready
/skynet-deploy
```

## How it works

1. **You share your idea** — type a short description of the website you want.
2. **Specialist agents take over** — one agent understands your idea, another plans the layout, another writes the content, and others handle design, code, testing, security, and SEO.
3. **Your site is built** — each agent does its part and hands off to the next, like a well-organized team.
4. **You review and launch** — see a preview, ask for changes, then deploy with one command.
